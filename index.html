The experiment, step by step

  1. What is a quantum eraser?

    It tests how interference changes when information that could distinguish paths is available. Erasing means measuring so the path is no longer knowable, not changing the past.

  2. The setup

    A laser pumps a BBO crystal, creating entangled signal and idler photons. The signal passes through the double slit while the idler takes a separate path.

  3. Why does the pattern disappear?

    When the paths are distinguishable in principle, the signal detections form a smooth envelope with no visible fringes.

  4. How do fringes return?

    Sorting detections by the idler result reveals complementary fringes, which cancel when combined. Signal detections alone stay fringe-free, so this cannot send a faster-than-light message.

Interference depends on whether the path is knowable in principle, not on whether anyone looked.
